# Portfolio

Bootcamp Project Portfolio

User Story: AS AN employer, I WANT to view a potential employee's deployed portfolio of work samples
SO THAT I can review samples of their work and assess whether they're a good candidate for an open position

Satisfies four out of six issues in GitHub.

Technology:
 - HTML
 - CSS
 - Flexbox
 - Media queries

 Live Website: https://rfields03.github.io/Portfolio/

Repository access:

 - Configure a ruleset for the Main branch to require pull requests and block direct pushes; keep administrator bypass limited.
 - Make the repository private in GitHub settings if the source should not be publicly viewable. Publicly served website content can still be copied.
 - Changing repository visibility or branch protection requires an authorized GitHub administrator and is not configured by this repository's files.
